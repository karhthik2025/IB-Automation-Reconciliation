# IB Operations Automated Reconciliation System

Automated Python script designed to streamline cash and position reconciliations between internal ledgers and custodian SWIFT MT940/MT950 feeds.

### Features & Value
- Automates Out-of-Balance (OOB) break detection.
- Categorizes discrepancy root causes (Amount Mismatch, Missing Feeds).
- Reduces manual reconciliation effort and supports SLA adherence.
